## 实验一 图像文件的打开与显示
- 使用Python+Pycharm进行相关环境配置
- 使用opencv函数打开（注意像素值）并显示图像（原图&RGB彩色图像三个分量图&不同亮度）
- 使用opencv灰度转换函数将彩色图像转换为灰度图像（RGB→gray）
- 使用opencv二值图像转换函数将图像转换为二值图像（RGB（gray）→binary）

## 实验五 图像复原
- 针对Lena图像运动模糊图像进行复原：
   - 退化过程一：运动模糊(45°方向运动了35个像素)
   - 退化过程二：在退化过程一的基础上叠加高斯噪声(参数：均值=0；方差=5)
要求：
   - 使用逆滤波对退化过程一进行复原，观察复原的效果
   - 使用逆滤波对退化过程二进行复原，观察噪声对复原有什么影响
   - 对退化过程二先消除噪声后，再进行复原，观察复原效果有无改善
- 对第一题中的退化过程二采用k参数进行维纳滤波复原，使其复原的效果尽可能接近原图
- 网上下载图片，采用大气湍流退化模型进行处理，再采用图像复原技术复原。已知退化模型为：H(u,v)=exp{-k[(u-M/2)2+(v-N/2)2)]5/6}，其中k=0.0025，M/2和N/2使得函数中心对称，以便与图像零点偏移后的傅里叶变换中心对齐

## 实验六 图像编码
- 对三种类型的图片【风景、花草、动物】：
   - 转换成灰度后，计算其一元灰度熵
   - 从一元灰度熵观察不同类型的图像差异，并分析灰度熵不同的原因。判断一元灰度熵能否作为图像分类的依据
- 对一幅灰度图像进行huffman编码：
   - 输出huffman编码情况
   - 计算平均码长R
   - 计算huffman编码的效率
- 对一幅灰度图像分解其各个位平面并显示，观察高阶和低阶位平面的低高频分布情况

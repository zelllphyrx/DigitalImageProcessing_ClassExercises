# DigitalImageProcessing_ClassExercises
# 数字图像处理课堂练习
*实验过程及结果见csdn博客：*

## 实验一 图像文件的打开与显示
- 使用Python+Pycharm进行相关环境配置
- 使用opencv函数打开（注意像素值）并显示图像（原图&RGB彩色图像三个分量图&不同亮度）
- 使用opencv灰度转换函数将彩色图像转换为灰度图像（RGB→gray）
- 使用opencv二值图像转换函数将图像转换为二值图像（RGB（gray）→binary）

## 实验二 频域图像处理
进行图像的Fourier变换及其反变换：
- 显示其频谱图
- 显示其相位谱图
- 显示其反变换的图像
进行图像的Fourier变换和离散余弦变换(DCT)：
- 显示DCT变换的频谱图
- 观察能量分布情况
